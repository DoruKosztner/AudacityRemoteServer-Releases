Privacy Policy — Remote Server for Audacity

Publisher: DoruTools • Last updated: November 2026 • Contact: dorutools@gmail.com

1. No Data Collection or Telemetry

Remote Server for Audacity (DoruTools) does not collect, store, share, or transmit any personal data, usage analytics, crash reports, or telemetry to external servers or third parties.

2. Local Network Communication Only

The application starts a local HTTP server on your Windows PC (default port 8765) so your phone, tablet, or iPad on the same local Wi-Fi network can send playback/recording commands to Audacity. All communication stays strictly within your local network.

3. Microphone Access (Live VU Meter)

The application reads real-time peak amplitude levels from the Windows audio input device (microphone) you select via WASAPI solely to display a live visual VU meter in the PC window and on your local web remote. Audio is never recorded, saved, or uploaded by this application.

4. Local Settings

User preferences (selected language, port, keyboard shortcuts, and welcome-screen preference) are stored locally on your PC in your user AppData folder (settings.json).

5. Contact

If you have any questions regarding privacy, contact the developer at dorutools@gmail.com.

Zásady ochrany osobních údajů — Remote Server for Audacity

Vydavatel: DoruTools • Kontakt: dorutools@gmail.com

Aplikace Remote Server for Audacity (DoruTools) nesbírá, neukládá ani neodesílá žádné osobní údaje ani telemetrii na externí servery. Veškerá komunikace mezi PC a mobilním zařízením probíhá výhradně ve vaší lokální Wi-Fi síti.

Přístup k mikrofonu (WASAPI) slouží pouze k měření okamžité úrovně signálu pro živý VU metr; aplikace žádný zvuk nenahrává, neukládá ani neposílá na internet. Uživatelská nastavení se ukládají pouze lokálně na váš počítač.
